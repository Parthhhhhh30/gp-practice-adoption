# CASEWORK — Support Investigation Desk

Independent fictional technical-support investigation exercise; not affiliated with Solve Intelligence or any law firm. Four reproducible case types, evidence recording, classification, specialist escalation, human-written responses, verified closure and reusable knowledge. Data is stored **only in this browser** using IndexedDB, not a shared authenticated database. No real legal matters, customers or external messages.

The optional server-side Gemini endpoint is **disabled by default**. To enable it later, configure GEMINI_API_KEY and CASEWORK_ALLOW_MODEL_CALLS=true in a secure Vercel environment; this may consume provider quota. The system never substitutes scripted text for actual model output. No paid subscription is required for the baseline.

Run rule tests: `npm test`. The eight routing evaluations are deterministic and **not a model evaluation**. Real model-backed evaluation remains an additional release gate.
